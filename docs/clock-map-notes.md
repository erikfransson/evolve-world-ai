# Clock map notes

Running log for the clock map (new Live World map replacing the Inland Sea). Appended, not rewritten.

## Objectives and status

| ID | Objective                                                                 | Status      |
|----|---------------------------------------------------------------------------|-------------|
| M1 | Map design: 6 outer biomes + common hub, desert gaps, highways             | open        |
| M2 | Look: polished, styled like the Live page, independent style reviews       | open        |

## Decisions (Erik, 2026-11-08)
- Replace the Inland Sea on Live (fresh world).
- 6 outer regions + center hub.
- 60000 x 37500 (was 50000 x 31250).
- One founder per region at seeding.
