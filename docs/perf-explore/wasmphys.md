- Math: `Math.sin` and `Math.cos` are imported into the module and called per creature, so rows equal the JS path on any engine. `Math.exp` is only in `decaysFor`, evaluated once per species per call in JS and written into the species block, so no import is needed. The imported calls cost little: the phase is 0.45 us per creature against 0.6 JS, the earlier inlined fdlibm kernel was 0.48 us.
- Layout: all row, call block (`P_*`) and species block (`Q_*`) offsets are in `layout.ts`, substituted into `step.wat`. Terrain constants (`CLEAR_CELL`, `ROCK_CELL`, rock tables, rasters via `Terrain.nearFor`) go in through the call block from their TS definitions.
